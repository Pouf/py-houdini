# Contributing Guide

## Quick Start

1. **Fork and clone** the repository (fixtures are stored with Git LFS)
2. **Install**:

    === "uv"

        ```bash
        uv sync --extra dev
        ```

    === "pip"

        ```bash
        pip install -e ".[dev]"
        ```

3. **Test**: `uv run pytest`
4. **Submit a pull request**

## Key Topics

- **Architecture** - A lossless container (`container.py`), codecs over section bytes returning token offsets (`sections.py`, `hscript.py`), and a scene model on top (`scene.py`, `replace.py`)
- **Round-trip first** - Parsing then saving without edits must give the same bytes; files that cannot be reproduced are refused at parse time
- **Token edits** - Edits splice single tokens into their section; untouched bytes are never rewritten
- **Ground truth from Houdini** - Fixtures in `samples/models/` are made by Houdini (`scripts/hython/make_fixtures.py`), each with a JSON dump of Houdini's own view (`scripts/hython/dump_scene.py`); tests compare the model against them
- **Generated data** - `data/node_types.py` is generated by `scripts/gen_node_types.py` from Houdini's node types; regenerate it, never edit it by hand
- **File format notes** - Every finding goes to [File Format](file_format.md), marked as measured or observed
- **Code style** - Python 3.7 compatible, fully typed (`mypy`), linted and formatted with `ruff`
